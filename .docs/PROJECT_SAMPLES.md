# Project sample screens

The portfolio includes nine sample screens across its seven projects. Open a project modal and choose **View sample**. CarbonSense and FinShield use React components copied from their original Next.js dashboards. DaguConnect and AnchorWatch provide desktop/mobile tabs; Send Notes uses a phone frame. PALDEX copies the original home screen design and CSS. **Project details** returns to the case study; **Open sample** opens the seven standalone samples separately.

Dashboard records use fictional data. CarbonSense and FinShield retain source presentation code; PALDEX retains its source home markup, unchanged `Home.css`, and referenced artwork. The Flutter/Android/Java samples translate their source layouts for browser previews. These are dashboard/home samples, not deployed applications. The original project folders are only read: no original project is installed, built, started, or connected to a service.

## Implementation

- `src/lib/projectSamples.ts` maps project IDs to native React dashboards or static screen URLs and the available formats.
- `src/components/project-samples/carbonsense/` copies the dashboard page, stats cards, recent activities, category legend, quick actions, carbon footprint chart, and original card/chart/button/badge primitives. Its horizontal navigation retains source visual markup, with account services removed. `fixtures.ts` supplies the original hooks' view data locally.
- `src/components/project-samples/finshield/` copies the company-owner dashboard presentation, chart components, chart filters, inventory health chart, UI primitives, invoice table, status badges, and desktop sidebar markup. Authentication guards, loading/service branches, and backend prompts are excluded. Fixtures supply revenue, stock, invoice, branch, and owner records; filters and sidebar collapse operate locally. Each copied file identifies its original path.
- `NativeSampleFrame` lazy-loads these components through a React portal into a same-origin document for CSS isolation. Its sandbox omits script permission; the portfolio owns React execution. It copies local font-face rules, reuses CarbonSense's Geist family, and loads FinShield's original Inter family with Next font. Original logos are optimized for display in `public/project-samples/assets/carbonsense/` and `finshield/`. `SampleLink` intercepts original navigation without calling services. Escape forwards to the modal.
- `src/components/ui/ProjectSampleViewer.tsx` presents the samples inside the existing project dialog. It supports keyboard-operated variant tabs, a loading state, a fallback link, and focus transfer when opening/returning.
- `ProjectPreview` retains its native dialog, certificate-style opening/closing, scroll locking, hidden scrollbar, Escape/backdrop dismissal, and opener focus restoration. Its focus loop includes the new controls and iframe.
- `public/project-samples/` contains seven standalone HTML samples, shared/per-project CSS/JS, copied source art/fonts, native dashboard CSS, and deterministic fixtures. The static samples use an iframe with `sandbox="allow-scripts"` and no same-origin permission. Native React samples use `sandbox="allow-same-origin"` without script permission. Neither permits top-level navigation, forms, or popups.
- PALDEX loads the unchanged source `assets/paldex/Home.css` followed by `paldex-preview.css` for modal sizing, keyboard access, reduced motion, and a pause/play control. `paldex-preview.js` preserves the source book toggle while keeping navigation within the home-only preview. Source raster assets are encoded as WebP for display. The complete original 26.7-second desktop/mobile videos are re-encoded without audio for the embedded view, preserving their scenes; posters are extracted from them. Browser widths up to 980px select the original mobile scene. The generic creature-grid recreation is removed.
- AnchorWatch mobile translates Flutter's light theme values and card sizing, horizontal article carousel, unified table, chart order, AI-summary panels, and 60px bottom navigation. Its five navigation icons and drawer logo use WebP copies of the source art; four Inter font weights remain byte-for-byte source copies. Monthly/Yearly switching, summary expansion, and the drawer operate locally; all summaries and articles are fictional, with no AI or market service calls. Charts/table regions can scroll horizontally as in the Flutter source, without overflowing the phone frame.
- Sample CSP blocks connections and form submissions. No remote libraries, API calls, authentication, credentials, persistence, or real records are included. The original `PROJECTS/` files remain unchanged.
- Navigation to other application screens is intentionally inactive. Search, Send Notes content filters, DaguConnect service filters, U-Cash history, AnchorWatch period/summary controls, and the PALDEX book menu operate locally. Other actions explain the sample's home/dashboard scope.

## Data and regeneration

`scripts/generate-project-samples.mjs` copies selected local art/font assets and writes the seven non-Next sample pages plus `fixtures.json`. It delegates PALDEX and AnchorWatch mobile to `scripts/project-samples/paldex.mjs` and `anchorwatch-mobile.mjs`. PALDEX preparation requires an installed FFmpeg only when its optimized videos/posters are absent; existing media is reused. It does not execute project code. Shared and project-specific CSS/JS are maintained directly. Run the generator only when changing a standalone screen's markup or fixtures. The generated assets remain usable without the original folders or FFmpeg during ordinary portfolio builds.

`node scripts/build-native-sample-styles.mjs` compiles the copied dashboard styles through the portfolio's installed Tailwind/PostCSS tooling into `carbonsense-native.css` and `finshield-native.css`. Run this after changing copied dashboard classes or tokens and include the generated CSS. No original project code, server, or build is executed. The generated CSS is included in the portfolio, so ordinary static export needs no original project folder. Recharts and the original primitive dependencies are recorded in `package.json` and `package-lock.json`.

Invoice sales/net revenue, daily/weekly carbon totals, booking counts/statuses, stablecoin volume, and U-Cash expenses are reconciled from their displayed sample fixtures. The viewer labels samples as fictional data; PALDEX shows original project artwork and scenes rather than invented records. AnchorWatch mobile fixture rows and article copy are also saved in `assets/anchorwatch-mobile/fixtures.json`.

## Verification boundary

Verification uses TypeScript, targeted lint, and an isolated browser harness compiling only the portfolio's copied sample/viewer components. Desktop and phone checks cover original chart rendering, local assets, source filters, overflow, Escape, and focus restoration. The harness serves review artifacts through a temporary static-file server; it substitutes a font descriptor because Next font compilation belongs to the unrun Next build. Browser review therefore does not verify the final font download. No Next.js dev server, original project, backend, database, Gradle task, Java application, or production build is started for this work.
